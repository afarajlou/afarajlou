### About

My interests include computer architecture, AI acceleration, parallel computing, and hardware/software co-design. My master's research focused on accelerating k-nearest-neighbor-based leak detection in water distribution networks using parallel computing.

I'm currently exploring memory systems, efficient LLM inference, GPU computing, and neuromorphic architectures.

### Selected work

- **Hardware/software co-design:** Neural-network acceleration on Zynq using VHDL IP and HLS.
- **Parallel computing:** CUDA neural-network implementation; distributed matrix multiplication with OpenMP and MPI.
- **Computer architecture:** Cache performance analysis using gem5.
- **Reconfigurable computing:** Image processing on PYNQ for robotics.
